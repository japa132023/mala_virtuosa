## 🚀 Como Publicar no GitHub Pages

### 1. Criar o repositório
1. Acesse [github.com/new](https://github.com/new)
2. Nome: `mala-virtuosa`
3. Deixe **público** ✅
4. Clique em **Create repository**

### 2. Fazer upload dos arquivos
1. Na página do repositório, clique em **"uploading an existing file"**
2. Arraste os arquivos:
   - `index.html` ← **principal**
   - `manifest.json`
   - `icon_mala_virtuosa.png`
3. Clique em **Commit changes**

### 3. Ativar o GitHub Pages
1. Vá em **Settings** → **Pages**
2. Em *Source*, selecione **Deploy from a branch**
3. Branch: **main** | Pasta: **/ (root)**
4. Clique em **Save**

### 4. Acessar o app
Após ~2 minutos, acesse:
```
https://SEU_USUARIO.github.io/mala-virtuosa/
```

## 📲 Instalar no Celular (como app)

### Android (Chrome)
1. Abra o link no Chrome
2. Aparecerá um banner **"Instalar no celular"** na tela de login
3. Toque em **Instalar** → confirmado!

### iPhone (Safari)
1. Abra o link no Safari
2. Toque em **Compartilhar** (ícone de caixinha com seta)
3. Escolha **"Adicionar à Tela de Início"**
4. Toque em **Adicionar**

## 🔒 Segurança

- PIN criptografado localmente no dispositivo
- Todos os dados ficam **apenas no aparelho** (localStorage)
- Nenhum dado é enviado para servidores externos
- Botão de bloqueio rápido no topo do app

---

## 🛠️ Tecnologias

- **HTML5 + CSS3 + JavaScript** puro (zero dependências)
- **PWA** (Progressive Web App) — funciona offline
- **localStorage** para persistência dos dados
